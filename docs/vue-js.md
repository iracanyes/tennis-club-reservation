# Vue.js

## Installation
Here we install a Vue.js app with Vite.js a build tool and dev server
````bash
$ mkdir /path/to/[project_name]
$ npm create vite@latest [app_name] -- --template vue-ts
$ cd <your-project-name>
$ npm install
$ npm run dev
````
Next, we add some dependencies

````bash
$ npm i vue-router
$ npm i -D tailwindcss @tailwindcss/vite
````
